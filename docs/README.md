## Idea file template
Every file in `ideas/` follows the same structure so the team (and AI assistants) can compare them:
1. One-liner
2. The problem in Jordan (facts + links)
3. Who is left out today
4. Proof it works elsewhere
5. What we'd build (11-hour MVP)
6. Where the AI adds real value
7. Scorecard vs judging criteria
8. Risks / open questions
9. Business / scale path
10. Demo sketch (optional)
