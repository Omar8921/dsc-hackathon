## 1. Farz: ED triage copilot
- **Problem (Jordan):** ~1.5M public ED visits a year, only 6.4% admitted. 61% of patients don't know triage exists. 63% of Amman doctors faced violence last year, mostly in EDs.
- **Unique:** Jordanian-dialect voice intake → LLM extracts → *rules* score (CTAS/ESI-style). **AI may only escalate.** A **family-facing wait-transparency screen** aimed at the anger/violence loop. Low-acuity patients are redirected to the nearest health centre. English handover note for the doctor.
- **MVP:** kiosk intake, scoring engine, live nurse queue (confirm/override), family screen, handover card, measured agreement on ~40 vignettes.
- **Profit:** private hospitals (SaaS per ED; medical tourism makes multilingual valuable), MoH/RMS tender via Hakeem, insurers/TPAs (avoidable ED claims).

## 2. Adaptive Learning Studio (includes the personalised roadmap builder)
- **Problem (Jordan):** learning poverty 52% → 60%+; PISA 2022 math 361 (lowest ever); 826 double-shift schools; classes of 45+. Only families who pay for tutoring get personalisation.
- **Unique:** evidence-based diagnosis (not "what's your level?"); output is **interactive modules** (typed presets filled by AI, not text); one learner model (concept graph + mastery + mistake log) drives the map, exams, weak-point history and capstones; Arabic and Jordanian curriculum.
- **MVP (classroom mode):** textbook photo → 4 module types (Quiz with misconception-tagged distractors, Simulation, OrderSteps, ConceptMap) → QR for students → live teacher dashboard → per-student map + generated remedial module.
- **Developer mode (the teammate's Golang case):** GitHub URL → static analysis (go.mod, goroutines/channels, context use, tests, error handling) + LLM review → evidence-linked skill map → code exercises + quizzes + **capstones that improve *your own repo***. Same engine, second market. ⚠️ Fits the economy sector better.
- **Profit:** free for teachers; private schools and donor programmes pay per student per year (MagicSchool ~$5/student, Diffit ~$3/student as anchors); B2C/bootcamp subscriptions for developer mode.

## 3. Nabd: CPR coach + volunteer responder alerts
- **Problem (Jordan):** cardiac-arrest survival ≈3% (secondary citation); only 29% of adults have any CPR training; ambulance 6.7 min urban / 11 min rural.
- **Unique:** camera pose-estimation CPR rate coaching with Arabic voice, plus geo-alerts to trained volunteers and an AED map.
- **MVP:** MediaPipe pose → compressions/min → voice + metronome; simulated volunteer alert; AED map; a *training mode* with scoring.
- **Profit:** training mode for companies, schools and universities (first-aid compliance, per-seat), Civil Defence partnership, health insurers.

## 4. Katib: Arabic ambient clinic scribe
- **Problem (Jordan):** 1,245 MoH health centres + Hakeem in 482 facilities means doctors type all day. Consultations are dialect + English code-switching. Patients leave with instructions they can't read back.
- **Unique:** Jordanian dialect + code-switching; the patient gets a simple-Arabic **audio** summary.
- **MVP:** record → STT → SOAP note (EN) + ICD-10 + Rx draft + patient summary (AR text + audio) → doctor approves.
- **Profit:** per-doctor subscription for private clinics; EHS/Hakeem deal.
- **Synergy:** Farz's handover note is a mini version of Katib, so they could be one product later.

## 5. Mish Mazbout: Arabic scam-message checker
- **Problem (Jordan):** 29,389 cybercrime court cases in 2025; 2,300+ fraud sites and 2,200+ WhatsApp numbers blocked; AI voice-clone "relative" scams (TRC, Mar 2026).
- **Unique:** dialect-aware explanations on WhatsApp (no app to install), one-tap reporting, built for elderly and low-literacy users.
- **MVP:** WhatsApp bot (Twilio sandbox) → classifier + LLM explanation + link/number checks → report flow → trends dashboard.
- **Profit:** banks/wallets and telcos (fraud losses, CBJ pressure) via B2B2C; TRC/PSD partnership. ⚠️ Fraud awareness is listed in the economy sector.

## Recommendation
**#1 Farz.** It has the best mix of all five filters: a hackathon-proven concept (Guardian took 1st), a Jordan-specific twist that no one else will have (wait transparency against ED violence), a credible payer, and a live demo with judge participation. Second choice: **#2** if the team wants an edtech "Lovable for X" platform.
