**Top 5 things not to forget**
1. **Submit by 1:00 PM, 10 Oct.** Pitches start at 1:30 PM: 7 min presentation + demo, then 3 min Q&A.
2. Answer the sector question out loud: **"Who does this reach that the current service does not?"**
3. **One loop working live** beats many features in slides.
4. **Say what's mocked.** It's part of the Technical score (15%).
5. **Arabic / RTL** in the UI (UX, 10%).
