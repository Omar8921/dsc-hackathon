# Pitch

| File | What it is |
| --- | --- |
| `faris-deck.html` | The pitch deck, in Arabic. Open it in Chrome or Edge. |
| `annotated.mp4` | Video shown on slide 9. It plays automatically when the slide opens. Keep it in the same folder as the deck. |

Deck controls: ← / PageDown / Space go to the next slide, → / PageUp go back, F toggles full screen, Home and End jump to the first and last slide. The deck loads its font from Google Fonts and falls back to a system font when offline.
